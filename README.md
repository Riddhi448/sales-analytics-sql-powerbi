# Sales Analytics Dashboard | SQL & Power BI

## 📌 Project Overview
This project is an end-to-end sales analytics solution built using **MySQL** and **Power BI** to analyze sales performance, profitability, and regional trends.

## 🛠 Tools & Technologies
- MySQL (Database & SQL Queries)
- Power BI (Dashboard & DAX)
- Excel / CSV (Dataset)

## 📂 Dataset
- Orders
- Customers
- Products
- Regions

## 🔗 Data Model
Relational model built using primary–foreign key relationships:
- Orders → Customers
- Orders → Products
- Customers → Regions

## 📊 Key KPIs
- Total Sales
- Total Profit
- Profit Margin %
- Total Orders

## 📈 Visualizations
- Sales by Sub-Category
- Profit by Category
- Region-wise Sales Performance
- Sales Trend Over Time
- Interactive slicers (State, Segment)

## 🔍 Key Insights
- Accessories and Storage are top-selling sub-categories
- Technology generates the highest profit
- East region contributes the highest sales
- Sales show a gradual decline over time

## 🚀 Outcome
This project demonstrates practical SQL querying, data modeling, and business-focused dashboard development using Power BI.
